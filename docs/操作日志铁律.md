## 三层铁律

### 第 1 层: 操作日志 (~/操作日志/YYYY-MM-DD.log)
- **谁**: 波哥 + 所有 AI 助手 / 脚本 / 定时任务
- **写什么**: 每一条 bash 命令
- **格式**: `HH:MM:SS [user@host:cwd] \$ command`
- **自动**: ~/.bashrc 加载 /root/scripts/log-hook.sh, PROMPT_COMMAND 自动记录
- **权限**: chmod 444 防篡改
- **保留**: 永久 (cp 到 /root/backups/每月备份)

### 第 2 层: DEV_LOG.md (重大动作)
- **谁**: 操作人统一格式 `操作人: <名字>/<agent-id>`
  - 波哥亲手操作: `操作人: 波哥/手动`
  - AI 助手执行: `操作人: 波哥/hermes` 或 `操作人: 波哥/trae` 或 `操作人: 波哥/claude-code`
  - 脚本/sync: `操作人: 波哥/脚本:sync-sgp-to-bj.sh`
- **写什么**:
  - ✅ MySQL 改动 (INSERT/DELETE/UPDATE)
  - ✅ 代码改动 (git diff 非空)
  - ✅ 跨服务器 sync (不论成功失败)
  - ✅ nginx 重载
  - ✅ pm2 restart
  - ❌ read/grep/dry-run 不写
- **路径**: `/root/src/docs/DEV_LOG.md`

### 第 3 层: git commit 身份
- **真实身份**: git config --global user.name="gdqboss" / user.email="gdqboss@gmail.com"
- **禁止占位**: `Hermes <agent@local>` / `hermes <hermes@local>` 这种占位身份 commit 视为可疑
- **修复方法**:
  1. `git config --global user.name "gdqboss"`
  2. `git config --global user.email "gdqboss@gmail.com"`
  3. 已 commit 的改 author: `git commit --amend --author="gdqboss <gdqboss@gmail.com>" --no-edit` (只改最新一个)

## 验证方法

```bash
# 1. 操作日志是否在写
tail -5 ~/操作日志/$(date +%Y-%m-%d).log

# 2. DEV_LOG 操作人字段是否合规
grep -E "操作人: (agent|hermes|ai)$" /root/src/docs/DEV_LOG.md  # 应为空

# 3. git 历史是否还有占位身份
cd /root/src && git log --pretty=format:"%an <%ae>" | grep -iE "agent|hermes|local"  # 应为空
cd /root/server && git log --pretty=format:"%an <%ae>" | grep -iE "agent|hermes|local"  # 应为空
```
